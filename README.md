## 📌 Project Overview

**ShopMe** is a modern, responsive, and fully functional e-commerce frontend built with **React**, **TypeScript**, **Tailwind CSS**, and **Vite**. It features clean design, component-based architecture, and client-side routing for seamless navigation across multiple pages.

---

## 🚀 Tech Stack

- **React** – component-based UI library  
- **TypeScript** – strongly typed superset of JavaScript  
- **Tailwind CSS** – utility-first CSS framework for styling  
- **Vite** – next-generation frontend tooling for lightning-fast builds and dev server  
- **React Router DOM** – for multi-page routing  
- **Heroicons** – for beautiful SVG icons  
- **Git & GitHub** – for version control and collaboration  

---

## 🧩 Features

- 🛍️ Multi-page layout (Home, Product Detail, Cart, Checkout, etc.)  
- 💅 Fully responsive and mobile-first design  
- ⚡ Fast development with Vite  
- 🧠 Type-safe React code using TypeScript  
- 🧭 Client-side routing with React Router  
- 🎨 Custom components with Tailwind and reusable styling

## 📁 Folder Structure

```bash
src/
│
├── assets/           # Static images and icons
├── components/       # Reusable UI components
├── pages/            # Page-specific components (Home, Product, Cart, etc.)
├── routes/           # React Router configuration
├── App.tsx           # Root component
└── main.tsx          # App entry point
```
## 🛠️ Setup & Installation
# Clone the repository
git clone https://github.com/Vaibhaverma-1/E-commerce-Website.git
cd E-commerce-Website

## Install dependencies
npm install

##  Start development server
npm run dev
